# Progressive level badges

Eight original transparent PNG badges generated with the built-in image_gen tool.

The redesigned family uses distinct materials and silhouettes, with an increasing footprint:

| Unlock | Structure |
| --- | --- |
| Level 1 | Small plain round wooden buckler |
| Level 5 | Copper heater shield with two chevrons |
| Level 10 | Blue silver shield with three chevrons and shoulder points |
| Level 20 | Amber-gold sunburst shield with ruby |
| Level 30 | Emerald shield surrounded by a gold laurel wreath |
| Level 50 | Crimson shield with large silver wings |
| Level 75 | Amethyst shield with gold wings and a royal crown |
| Level 100 | Diamond crest with double wings and celestial crown |

Unlock levels and earned XP are unchanged. Each tier increases visible structure rather than only changing the center gemstone or decorative trim.

Full-resolution masters: `masters/`. Prompt set: `prompts.json`. Preview: `progression.png`. Android exports: `app/src/main/res/drawable-nodpi/level_badge_*.png` (192px). Re-export using `tools/Export-LevelBadges.ps1` and regenerate the comparison using `tools/Preview-LevelBadges.ps1`.

The previous artwork is preserved in `archive-v1/`.
