# Pixel scenery, version 2

Eight individual opaque portrait PNGs generated with built-in image_gen. Exact prompts and original paths are recorded in `prompts.json`.

Meadow, sunset, moonlight, woodland, beach, snow, aurora and sky islands share a 2:3 composition with an open central ground plane. The active scene mapping uses `gameart_scene_v2_*`; previous scenery sources are preserved.

Building placement is independent of painted details. `WorldLayout.sites` supplies exactly five shared foot anchors for buildings, pixel stone pads and stepping-stone paths. Home uses a responsive 2:3 stage, bottom-aligned building sprites and a fixed footprint per stage size. Changing scenery cannot introduce extra or missing building slots. Text remains standard sans-serif.
