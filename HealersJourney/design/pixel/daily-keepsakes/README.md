# Daily trophies

Individual transparent PNG assets generated with built-in image_gen. Exact prompts are in `prompts.json` and `work-hammer-v2.json`.

The active collection uses Learning's book shrine, Work's golden hammer (`work-hammer-v2.png`), Fitness crystals, Social lanterns, and Creativity's ribbon sculpture. `work.png` is the retired stone monument draft. No tree or planting-board artwork is integrated.

Today presents completions on a wooden trophy shelf, eight per display. Items are derived from action history, not separate currency or fake completion records. Undo and selected historical dates use the same history. The shelf refreshes on state revisions and reveals the page containing the new completion. The Home building pads use the same five anchors as their buildings.
