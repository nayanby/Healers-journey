# Life RPG UI redesign

Four primary tabs: Home, Today, Growth, and More. Home presents a player progress card and three focused actions. Growth owns the six skill/recovery destinations. More groups finances, care, milestones, achievements, history, custom activities, and backups.

Shared surfaces, sans-serif typography, compact pill buttons, clear active navigation labels, and purple/teal/gold accents replace the previous drawer and repeated summary cards. All 46 colorful PNG assets are preserved.

Care routines share one compact list. Secondary analytics, history, maintenance forms, and achievement groups expand on demand. Empty daily plans start with the add-task form. Study has one hours-entry action; detailed statistics remain available.

Validation: Android debug build passed. Installed on Samsung SM-S928B. Reviewed Home, Growth, More, Today, Care, and Study in dark mode. Verified task-form expansion and Home → Study → Android Back. No test tasks or study sessions were recorded. Light-theme palette is implemented; visual phone checks used dark mode.
