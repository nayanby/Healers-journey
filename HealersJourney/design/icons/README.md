# Life RPG icon assets

The active replacement set is the colorful 3D PNG family documented in [COLORFUL.md](COLORFUL.md). Full-resolution generated masters are in `colorful/`, with the complete prompt set in `color-prompts.json`. The completed set is previewed in `colorful-catalog.png`.

`Build-Icons.ps1`, `manifest.txt`, and `catalog.png` describe the earlier line-icon version retained as source history. The app is switched to the colorful exports only after all masters are ready.
